# 林間卡牌（lin_card）｜試玩版 v0.6.3（回合開始換牌）

> 你所捨棄的一切，終將成為你的敵人。

《慢慢好玩遊戲區》獨立前端卡牌小遊戲。開啟 `lin_card/index.html` 試玩；部署 GitHub Pages 時，將整個 `lin_card/` 資料夾保持相對路徑上傳即可。**戰鬥抽牌使用慢慢軍火庫 Deck 1.1+ 的 HTTPS 公開函式**，所以執行戰鬥需要連線 `https://lib.stillnessbyslowly.com/`。軍火庫背景失敗時由宿主 CSS 背景接手。

## 正式採用的 v0.5 戰鬥規則（v0.6 維持不變）

| 類型 | 費用 | 主要效果 |
|---|---|---|
| 攻擊 | 行動點 | 造成傷害 |
| 防禦 | 行動點 | 暫時防禦 |
| 護盾 | 行動點 | 持續護盾 |
| 生命 | 行動點 | 回復 HP |
| 行動 | 行動點 | 裂盾／穿盾 |
| 特殊 | 免費／犧牲全部雙資源 | 補充行動點、補充魔法點、同命之契 |
| 魔法 | 魔法點 | 六種原特殊效果＋萬木共鳴 |

**魔法費用：**一葉歸塵 1、萬葉歸根 2、借影易形 3、斷枝奪葉 3、枯木逢春 4、移花接木 5、萬木共鳴 6。魔法、行動和特殊牌為固定效果，不進行普通等級升級；萬木共鳴強化施法者自己的可升級牌在當局的效果值（最多 Lv.5），**永遠不改變出牌費用**。

**行動費用：**裂盾 3 點直接清空敵方護盾；穿盾 2 點令下次自己的攻擊略過護盾但仍受防禦阻擋。其他可升級普通牌 Lv.0～Lv.5 基礎效果 5、6、8、11、15、20；費用為永久等級 +1。戰術分支延用四種普通牌。

**特殊牌：**Lv.0 免費補點牌回復 3 點行動或魔法點；同命之契耗盡施法者當下所有行動與魔法點，無視護盾，將**雙方當前 HP 都設定為 1**。消耗兩種資源合計至少要有 1 點才能發動；雙方護盾不清除。注意犧牲後需要再次補點，才可用一般攻擊收尾！

**雙方起手點數：**玩家行動 5 + 既往過關數、Boss 行動 5；雙方魔法 5。點數會在同一場戰鬥跨回合保留，特殊牌可以繼續補充；每次重新開戰恢復起手值。Boss 每回合隨機打出一張合法卡。

## 牌數與進度

- **七大類 × 每類固定 15 張**＝Boss 固定 105 張。
- 玩家開始固定五張攻擊牌，從額外 **40 張非攻擊牌選 25 張**，因此玩家初始收藏 **30 張**；剩 15 張交 Boss，Boss 初始牌庫 **120 張**。
- 初選 40 張分配：防禦 5、護盾 5、生命 5、行動 8、特殊 9、魔法 8；特殊包含三種效果各三張。Boss 固定特殊牌則為補行動點 5、補魔法點 5、犧牲 5。
- **永久收藏最多 80 張，每場攜帶最多 30 張**。Boss 牌庫沒有人為上限。
- 玩家每勝利一關，**額外固定獲得攻擊牌一張，下一關初始行動點 +1**；加上原本五選一的接龍名獎勵（新卡 1／2／3／4 張，或整副出戰牌的可升級卡升 1 級）。不用真的通關接龍。
- 玩家永久拒收／替換出去的卡牌加入 Boss；戰鬥內棄牌與交換不改永久歸屬。
- 戰鬥抽牌不自動循環；開局與每個回合補手牌至 4 張；玩家可以連續出牌、自行結束回合，Boss 隨機出一張合法牌。玩家無牌且無法再使用手牌時戰敗；認輸可同關重試。
- 十關生命、Boss 名字、固定牌隨關卡至 Lv.3 的成長維持舊版。戰鬥失敗不扣永久收藏，重新整理不恢復半場戰鬥。

**實際攻略提示：**初始選牌建議帶上裂盾、穿盾、免費補點、萬木共鳴與同命之契，避免把 25 個自由名額全部留給防守牌。犧牲要配合補行動點＋穿盾＋攻擊的出牌順序，並非立刻判 Boss 戰敗。隨機對局仍可能輸，這是試玩版，非保證勝利。

## v0.6 第一階段：入口及個人牌組

進入遊戲先看到「選擇關卡」「查看個人資料」。關卡頁顯示十關進度，只能挑戰目前關卡；已通關和未解鎖關卡暫時不能重玩。個人資料中可瀏覽永久收藏及 3 套牌組，各最多 30 張，玩家自行組牌。原 v0.5 的出戰牌自動成為牌組一，牌組二、三為空白；遊戲說明先隱藏，內容並未刪除。

## v0.6.1 第二階段：軍火庫 Tree 選牌介面

引用 `https://lib.stillnessbyslowly.com/state/tree_selection.js`，使用 `TreeSelection.create({ expansion: "single" })` 管理展開狀態，畫面樣式仍由宿主 CSS 掌管。初始 40 選 25 分六類；個人牌組編輯顯示七類。每個分類預設收合且互斥，打開分類後只列卡名，點「詳細」才能查看費用、效果、等級、戰術分支及加入／移出操作。分類內可看已選數量，三套牌組和出戰 30 張上限沿用原有邏輯。

此版**完全不修改**戰鬥與收藏存檔演算。軍火庫沒有網路連線時，會明確提示 Tree 尚未載入，不會假裝已接上零件。

## 程式拆檔

- `index.html`：HTML 結構與軍火庫絕對網址引用。
- `index.css`：功能本體卡牌 CSS。
- `index.js`：遊戲流程、初選、獎勵、收藏、關卡、舊存檔轉換。
- `index_style.css`：宿主畫面與手機 UI。
- `index_style.js`：卡面、扇型手牌、互動與戰鬥顯示。
- `cards.js`：卡片資料、七類名稱、費用、等級、描述。
- `battle_rules.js`：雙資源與魔法／犧牲／破盾實際結算。
- `save.js`：永久進度存檔，保留原 localStorage key。
- `changes_v0.6.md`：首頁與三套牌組的改動和測試範圍。
- `changes_v0.6.1.md`：本次 Tree 選牌介面與測試紀錄。
- `changes_v0.5.md`：前版七類卡牌詳細規則與相容性。
- `rules_v0.2.md`、`changes_v0.3.md`、`changes_v0.4.md`：**歷史版本規則／更新記錄，並非 v0.6.1 現行規則**。

舊 v0.4 已開局存檔首次載入會**保留原有關卡與收藏**，轉換舊卡分類、免費補 15 張功能牌、調整 Boss 固定牌庫；此升級只做一次。尚未按確認開始選牌的舊存檔會重建新版候選牌池。建議更新前備份瀏覽器資料。壓縮檔內使用英文字檔名，Markdown 內容 UTF-8，便於 Android 解壓。

此版是能玩的試驗版本，沒有把軍火庫的程式碼複製進專案，仍需網路載入軍火庫。


## v0.6.2｜Boss 剩餘牌數與雙方棄牌堆

- 戰鬥中的 Boss 牌數顯示為「剩餘可用＝抽牌堆＋手牌」，另外列出抽牌、手牌、棄牌數量；不透露 Boss 手牌內容。
- 「枯木逢春」現在能從**自己或對手的棄牌堆**取回 1 張；玩家可指定來源與卡牌，Boss 從雙方可取回卡中隨機選。
- 取回的牌放進**施法者手牌**。若取走對方棄牌，原棄牌堆少 1 張；此操作**僅作用於當場戰鬥**，不改永久收藏、出戰牌組或 Boss 永久牌庫。
- 其他卡牌費用、效果、勝敗、三套牌組與存檔規則不變。


## v0.6.3｜回合開始換牌

玩家每回合開始（尚未出牌或整理手牌時）可選一張手牌，免費棄入本場棄牌堆，並從自己的抽牌堆抽一張補上。每回合最多一次；抽牌堆空時不可使用。這不影響舊的「整理選中手牌」功能，Boss 不能使用。詳見 `changes_v0.6.3.md`。
