# lin_card｜林間卡牌（試玩版 v0.3）

> 你所捨棄的一切，終將成為你的敵人。

《慢慢好玩遊戲區》獨立回合制卡牌小遊戲。檔案以 `lin_card/` 為根目錄，開啟 `index.html` 即可；部署到 GitHub Pages 時可放在網站任一路徑下。**戰鬥使用慢慢軍火庫 Deck 1.1+，需網路可連上 `https://lib.stillnessbyslowly.com/`。** 背景森林／霧氣也引用軍火庫；如特效載入失敗會自動顯示 CSS 背景，不會複製軍火庫原始碼。

## 檔案職責

- `index.html`：網頁結構與公開軍火庫絕對網址引用。
- `index.css`：卡牌／戰鬥本體樣式。
- `index.js`：遊戲流程、收藏、十關、獎勵結算。
- `index_style.css`：宿主外觀與手機版排版。
- `index_style.js`：卡面、畫面、互動與宿主背景配置。
- `cards.js`：卡牌名稱、等級數值、類型與特殊牌資料。
- `battle_rules.js`：雙方牌庫、Boss 隨機出牌、行動點與六種特殊效果（以軍火庫 Deck 管抽牌／棄牌）。
- `save.js`：localStorage 永久進度。
- `rules_v0.2.md`：對應的遊戲原始規格。

## 快速試玩

1. 玩家固定領取 5 張專屬攻擊牌；其餘五類各 5 張（共 25 張）自由選 10 張。選剩 15 張歸 Boss，與固定 72 張合計初始 87 張。
2. 選擇本關出戰卡牌，最多 30 張；Boss 全部牌庫參戰。
3. 玩家點一下卡牌選取，再點同一張出牌；當回合可連續使用合法牌，手動結束回合。Boss 從自己的手牌隨機使用一張能支付的卡。
4. 戰鬥後從原五種接龍命名的獎勵中五選一，**直接領取**，不用真的打接龍；獎勵會確實寫入 localStorage。
5. 第 5 關失敗仍重試第 5 關；永久收藏、Boss 收到的棄牌、卡牌等級完整保留。第 10 關完成通關。

## 第一版測試採用的暫定細節

- 每次自己的回合開始，手牌不足 4 張補到 4；Boss 回合補到 4，隨機出 1 張合法手牌。
- 防禦為當次敵方行動的防護（下次自己的回合清除）；護盾跨回合保留。受傷先扣防禦，再扣護盾，最後扣生命。
- 行動牌 Lv.0 補 1 點，每升 1 級多補 1 點，出牌費用永遠 0；行動點可超過 5，只有每場戰鬥開始重設至 5。
- 換手牌／強制棄牌從隱藏的 Boss 手牌隨機處理；玩家可指定自己的被棄／被交換牌。戰鬥內交換不影響永久收藏歸屬。
- 戰鬥內棄牌只進本場棄牌堆；只有永久拒領獎勵／永久替換舊卡才會送 Boss。
- 特殊牌「枯木逢春」把本場棄牌堆一張牌帶回手牌，不等於尚未開放的玩家原地復活。
- 玩家每回合可免費整理（棄置）自己一張手牌，避免行動點卡死；**此為 v0.1 測試用暫定機制，非使用者已拍板規則**。
- 初始共同牌池 5 張特殊牌從六種名稱依序取前五張；Boss 固定六種各 2 張。獎勵池允許同名卡牌作為不同實例。
- 普通牌 Lv.1 起可選「標準／其他兩種」戰術分支，現階段免費重選；具體重選成本未定，支援簡單分支額外效果。
- Boss 固定 72 張可升等牌隨關卡達 Lv.3；從玩家得到的牌永久保留交付當時的等級，未再套用關卡加成。
- 重新整理時保留永久進度與尚未領完的戰後獎勵，但**不恢復半場戰鬥**，回到同關選牌畫面重新開始。
- 因第一版 Boss 和玩家手牌規模差距極大，目前尚未做精細平衡；真實接龍以及 Spider 高階原地復活均尚未開放。

## 軍火庫範圍

使用 `Deck.create({ items, handSize: 4, recycleDiscard: false })` 和它公開的 `drawToHand()`、`discardAt()`、`discardAll()`、`snapshot()`、`restore()`。其他效果是宿主自己的新戰鬥規則，**沒有複製或修改 `card_battle_component.js` 或 Deck 實作**。若未來軍火庫公開新通用介面，再評估是否替換。

**本版為可玩測試版，不是最終平衡、正式卡牌插圖或對戰 AI。**

## v0.2 戰鬥介面（對照鹿雨森 Demo）

- 直接對照使用者提供的 `silvarain/demo/card/` 原始碼與 CSS 設計：**上方中央 Boss 霧影、血條／狀態、下方重疊扇形手牌、底部玩家 HUD、右側結束回合**。
- 點一次抬起選牌，點第二次正式出牌；成功出牌有飛向對應目標的視覺動畫，Boss 結束回合有動作回饋；支援手機窄螢幕及減少動態效果設定。
- 延續 Demo 的森林意象與卡面布局，但不引用鹿雨森官網標誌、導覽或角色劇情資產。
- **這次只有介面更新，不改卡牌數值、十關進度、特殊牌邏輯、存檔及軍火庫呼叫方式。**
- 中文 Markdown 的**內容**使用 UTF-8；為避免部分 Android ZIP 解壓軟體把**中文檔名**解讀成亂碼，壓縮包裡改用純英文檔名 `rules_v0.2.md`。

## v0.3｜抽牌、敗北與勝敗判定修正

- 初始從「30 選 15」改成**5 張攻擊牌直接入玩家收藏**，其餘五類 **25 選 10**；剩下 15 張歸 Boss，初始仍 87 張。既有已開局的舊版存檔不強制清空；尚在選牌畫面的舊版存檔會重建新選牌池。
- 新增戰鬥畫面的 **「敗北／認輸」** 按鈕，點擊後需確認才會認輸；保留永久進度，回同一關重試。
- **只有抽牌堆空且手上完全沒牌，或剩餘手牌全部不合法／行動點不足時才判定卡牌耗盡戰敗。** 抽牌堆空但手上仍有合法卡，不會過早判輸；也不因為回合數增加自動補出牌。
- 玩家 HP 歸零優先判敗；同時歸零同樣是玩家戰敗；勝敗結算不可重複覆蓋。Boss 無牌可出仍遵守原本規則。
- 戰後獎勵按鈕改顯示「選擇獎勵」，不用通關接龍，沒有修改獎勵計算。
- 軍火庫 Deck 仍透過 HTTPS 絕對網址引用，**沒有修改軍火庫**；森林戰場、扇型手牌及存檔路徑皆保留。
