# v0.7｜《霧林之契》正式開場與專案拆檔

- **重新命名**：《林間卡牌》→《霧林之契》，目錄 `lin_card/` → `mistforest_pact/`。HTML title / meta description、頁首主標、README 同步更名；現有 `LinCard*` 模組識別字不需為更名而冒險改動戰鬥。
- **新開場**：開網頁先顯示以 CSS、Canvas、SVG 製作的霧林。中央「霧林之契」可點擊進場；點擊後才顯示原本「旅人的選擇」兩個選項。進場時淡出開場。

- **頁首頁尾**：移除「返回慢慢遊戲」「重新開始」按鈕與主標上方英文小標；保留下方原英文 `The Forest Keeps What You Leave Behind`。頁尾只留純文字 `慢 慢 | Stillness by Slowly`、不連結。
- **乾淨拆檔**：開場背景／動畫／聲音獨立 `opening/`；主遊戲改置於 `game/`；共通宿主樣式分離為 `site.css`；移除舊卡片 Demo 閒置 CSS、舊版異動紀錄與多代舊存檔遷移程式。隱藏中的遊戲說明保留為 `docs/game_guide_draft.md` 草稿，不在頁面輸出。
- **存檔重新起算**：新 key `mistforest_pact_save_v1`、schema version 3；不載入／不覆蓋舊 `lin_card_save_v1`，新版本從初始選牌開始。**仍有 v0.7 的永久存檔功能**。
- **僅修正 UI 上限數值**：戰後領獎「收藏已滿」判斷由誤寫的 60 修正為規則本來的 80。戰鬥牌的數值、效果與 Boss 邏輯未變。
- **延後項目**：「旅人的選擇」主選單美化、其他戰鬥介面感受留待後續討論。
