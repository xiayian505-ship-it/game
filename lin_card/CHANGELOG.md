# v0.7｜《霧林之契》正式開場與專案拆檔

- **重新命名**：《林間卡牌》→《霧林之契》，目錄 `lin_card/` → `mistforest_pact/`。HTML title / meta description、頁首主標、README 同步更名；現有 `LinCard*` 模組識別字不需為更名而冒險改動戰鬥。
