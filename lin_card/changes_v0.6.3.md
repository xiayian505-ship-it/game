# 林間卡牌 v0.6.3｜回合開始棄一抽一

本次只新增玩家回合開始的換牌功能，不動卡牌效果、Boss 出牌、選牌／三套牌組、獎勵或永久存檔規則。

1. 玩家每個回合開始時，可選擇一張手牌棄入自己的**本場棄牌堆**，再從**自己的抽牌堆**抽一張；不消耗行動點或魔法點。
2. 一回合最多換一次；開始出牌、使用原有「整理選中手牌」、或結束回合後，當回合換牌機會失效。可以直接不換。
3. 抽牌堆為空不能換；抽出的牌就是原本牌庫的下一張，不從棄牌堆重洗。
4. 原有「整理選中手牌」保留：它只棄牌、不補抽，而且和新換牌各自計次。
5. 新按鈕只在回合開始且抽牌堆仍有牌時出現在手牌區，先選一張牌才可以按下；交換後更新手牌和戰鬥紀錄。
6. 戰鬥內牌張數不涉及永久收藏移轉，Boss 沒有免費換牌權。

涉及檔案：`battle_rules.js`、`index.js`、`index_style.js`、`index_style.css`、`index.html`、`README.md`。
