# 林間卡牌 v0.6.1｜第二階段：選牌 Tree 收合

本版只調整**初始選牌與個人牌組出戰編輯**的呈現，不修改遊戲進度、永久收藏結構、三套牌組儲存、戰鬥計算、Boss、卡片數值與獎勵。

## 新介面

- 引用慢慢軍火庫原有 `https://lib.stillnessbyslowly.com/state/tree_selection.js`（Tree Selection v1.0.0）；不複製零件程式碼進入本專案。
- Tree 的 `expansion: "single"` 負責**分類互斥收合**。第一次開畫面全部收合；展開新分類會自動關閉上一分類；同類別再點一次可收起。
- 新玩家初始 40 選 25 依六類分組；出戰選牌則顯示七類（收藏中沒有的類別顯示「目前沒有此類卡牌」）。
- 展開分類時只顯示卡牌**名稱**、已選取記號及「詳細」按鈕；不把全部卡面一次列出。
- 點「詳細」才顯示類型、永久等級、行動／魔法費用、卡牌效果、可選的戰術分支、加入／移除操作。
- 分類標頭顯示「已選 N / 該類總數」；選牌總數顯示 25／30 的上限。
- 點擊加入或移出後保留目前打開的分類及詳細內容，方便手機連續選牌。
- 三套牌組繼續各自儲存；出戰頁的標題標明目前編輯的牌組編號。

## 此次修改

- `index.html`：僅新增軍火庫 Tree 的 HTTPS 絕對網址及微版號文字。
- `index_style.js`：用宿主渲染分類名稱清單、卡牌詳細和點擊事件。
- `index_style.css`：新增選牌 Tree 的手機樣式，全由宿主控制外觀。
- `README.md`：更新使用說明。

## 未修改

- `index.js`、`cards.js`、`battle_rules.js`、`save.js`、`index.css`、原軍火庫程式碼、其他舊版規則／更新記錄。

## 檢查

- 全部本機 JS 語法檢查。
- Chromium 手機尺寸實際互動：初始六類、出戰七類、預設收合、互斥展開、點名詳細、卡牌選取／取消、詳細狀態不關閉。
- 模擬第七關舊存檔：三套牌組分別紀錄，重新開啟後資料仍在；卡牌永久等級正確呈現。

注意：測試環境無法直接連外，瀏覽器互動測試以**同 API 的 Tree 測試替身**模擬載入；實際部署則會引用軍火庫公開的 Tree Selection 真正程式。軍火庫原始檔 API 已對照檢查。
